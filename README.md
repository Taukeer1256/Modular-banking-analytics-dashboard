# 🏦 Modular Banking Analytics Dashboard

An executive decision engine answering one core product strategy question:  
> **"Which banking module should a small bank launch first?"**

Built with **real public data** from the **National Payments Corporation of India (NPCI)** and the **Reserve Bank of India (RBI)**, this project features an automated data cleaning pipeline, a SQLite database with 5 analytical queries/views, a multi-criteria decision analysis (MCDA) opportunity scoring engine, a high-aesthetic interactive Streamlit dashboard, and a full pytest test suite.

---

## 🎯 The Product Recommendation (with Strategic Caveats)

### Executive Finding: Launch **UPI & Instant Payments** First, Followed Immediately by **Digital Onboarding & CASA**

```
  ┌────────────────────────┐      ┌────────────────────────┐      ┌────────────────────────┐
  │   Phase 1 (Month 0-3)  │      │   Phase 2 (Month 2-5)  │      │  Phase 3 (Month 6-12)  │
  │  UPI & INSTANT PAYMENTS│ ───► │ DIGITAL ONBOARDING/CASA│ ───► │  DIGITAL MICRO-LENDING │
  │   Acquisition & DAU    │      │   Sticky Deposit Float │      │  High-Yield NIM (8-14%)│
  └────────────────────────┘      └────────────────────────┘      └────────────────────────┘
```

#### Why Payments Wins:
1. **Unrivaled Market Growth & Consumer Pull:** Real NPCI statistics show UPI processed **171.6 Billion transactions in 2024** (up **+45.9% YoY**), commanding **~75% of all digital transaction volume** in India. No other banking product offers equivalent organic user acquisition velocity.
2. **Speed to Market & Capital Efficiency:** Modern cloud-native payment switches and TPAP/PSP partner rails enable launch in **3–4 months** with modest initial capex, compared to 9–12+ months for credit underwriting stacks.
3. **Zero Balance-Sheet Credit Risk:** A small bank or Small Finance Bank (SFB) has limited capital cushions. Payments routing carries transaction routing and fraud risk, but **zero credit default risk** (NPA vulnerability is 0%).
4. **Behavioral Telemetry as a Credit Precursor:** High-frequency payment interactions provide cash-flow visibility into retail and MSME merchant income, building the proprietary data foundation necessary to underwrite digital loans later without adverse selection.

#### Critical Caveats & Trade-offs:
* **The Margin Trap:** UPI operates under government zero-MDR mandates for peer-to-merchant transactions under ₹2,000. Standalone payments generate minimal interchange fee income. **Payments must be treated as a loss-leader / customer acquisition hook**, not a standalone profit center.
* **The CASA Sequencing Mandate:** A small bank must sequence **Digital Onboarding & CASA** within 60–90 days of payments launch to convert transaction volume into low-cost savings account balances (3–4% cost of funds vs 7.5%+ wholesale borrowing).
* **Credit Timing:** While **Digital Lending** delivers the highest margins (NIM 8%–14%), launching lending on Day 1 is perilous for small institutions due to capital adequacy requirements, credit bureau lag, and collection overhead.

## 🗄️ The 5 SQL Queries (in SQLite)

The SQLite database (`banking.db`) includes 3 tables (`upi_monthly`, `rbi_payment_systems`, `banking_modules`) and 5 persistent views:

1. **Query 1: Year-over-Year (YoY) Growth Rate (`v_upi_yoy_growth`)**
   * Computes annual volume and value totals, prior year comparisons, and percentage expansion.
   * *Insight:* UPI grew from 117.6B transactions (2023) to 171.6B transactions (2024), a **+45.86% volume expansion**.
2. **Query 2: Month-over-Month (MoM) Changes (`v_upi_mom_change`)**
   * Uses SQL `LAG()` window functions across chronological months to track monthly velocity and ticket size trends.
3. **Query 3: Seasonality Analysis (`v_upi_seasonality`)**
   * Groups records across calendar months (Jan–Dec) to compute an index relative to the grand mean.
   * *Insight:* Highlights festive shopping surges in October/December and financial year-end corporate settlements in March.
4. **Query 4: Share by Channel (`v_channel_share`)**
   * Measures retail vs wholesale payment system shares (UPI, NEFT, RTGS, IMPS, FASTag).
   * *Insight:* UPI controls **74.98% of volume** but only **3.73% of settlement value**, whereas NEFT/RTGS settle over **96% of value**.
5. **Query 5: Opportunity Score Query (`v_opportunity_score`)**
   * Multi-criteria decision analysis (MCDA) combining market growth rate (25%), volume scale (20%), speed to market (25%), margin potential (15%), and credit risk safety (15%).

## 🚀 Getting Started

### 1. Prerequisites & Environment Setup
Python 3.10+ is recommended. Install required packages:

```bash
pip install streamlit plotly pandas pytest
```

### 2. Run Data Cleaning & Database Build
Execute the cleaning script to validate raw data, generate drop logs, and create `banking.db`:

```bash
python data/clean_data.py
```

*Output:*
```
2026-10-08 19:15:30  INFO  Reading UPI raw from .../data/npci_upi_raw.csv
2026-10-08 19:15:30  INFO  UPI clean complete: 32 -> 32 rows (0 dropped)
2026-10-08 19:15:30  INFO  Reading RBI raw from .../data/rbi_payment_systems_raw.csv
2026-10-08 19:15:30  INFO  RBI clean complete: 15 -> 15 rows (0 dropped)
2026-10-08 19:15:30  INFO  SQLite DB build complete with 3 tables and 5 analytical views.
```

Inspect `data/clean.log` to review every logged validation step.

### 3. Run the Pytest Test Suite
Verify that all 18 automated tests pass:

```bash
python -m pytest -v
```

*Test Coverage:*
* **`tests/test_cleaning.py`**: Null handling, invalid type coercion, negative volume rejection, duplicate prevention, and drop logging.
* **`tests/test_database.py`**: Table existence, view execution, and verification of all 5 standalone `.sql` files.
* **`tests/test_scoring.py`**: Weight normalization, scoring math, sensitivity to margin/safety shifts, and dynamic recommendation generation.

### 4. Launch the Streamlit Dashboard
Start the web dashboard locally:

```bash
streamlit run app.py
```

The application opens at `http://localhost:8501`.

## ⚠️ Limitations & Analytical Caveats

1. **State-Level Granularity:** Public NPCI datasets aggregate UPI statistics at the pan-India national level. A Regional Rural Bank (RRB) or localized Small Finance Bank should supplement national growth trends with state-specific SLBC (State Level Bankers' Committee) transaction data.
2. **Third-Party Switch Dependencies:** Launching UPI requires partnering with a certified payment switch provider (e.g. Zeta, M2P, Sarvatra) or sponsor bank. Operational uptime and latency SLAs must be scrutinized.
3. **Regulatory Evolution:** The RBI periodically reviews digital payment MDR structures and interchange caps. Changes in interchange policy could alter unit economics over time.
